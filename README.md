# Джарвис Лайт — лёгкий голосовой помощник для Windows без ИИ

📖 **Подробная инструкция для новичков: [docs/ИНСТРУКЦИЯ.md](docs/ИНСТРУКЦИЯ.md)** (её же открывает пункт
«Инструкция» в меню значка у часов).

**Джарвис Лайт** — отдельная лёгкая версия [Джарвиса](https://github.com/kravakos13/jarvis-voice-assistant)
**без нейросети**. Все команды на месте: окна, программы, музыка, YouTube, вкладки, файлы, поиск, клавиши, набор
текста, таймеры, напоминания, заметки, погода, тревоги, умный дом. При этом он **почти не нагружает компьютер**:
нет Ollama и языковой модели, видеокарта не используется, распознавание речи идёт на процессоре.

К тебе обращается «мистер Флоки» (меняется в настройках). Голос — Piper, распознавание — Whisper small (int8).
Работает без интернета; интернет нужен для установки, погоды и поиска.

## Установка

1. Скачай **[JarvisLiteSetup.exe](https://github.com/kravakos13/jarvis-lite/releases/latest/download/JarvisLiteSetup.exe)**
   (последняя версия, ~15 МБ) и запусти. Права администратора не нужны.
2. Оставь галочку «Скачать голос и распознавание речи» — установщик докачает около 1 ГБ (3–10 минут).
3. Готово: возле часов появится **мятный значок с буквой L**. Скажи «Джарвис, привет».

Из исходников: `install.bat` (Python 3.10–3.12), затем `run.bat`.

**Что нужно:** Windows 10/11 x64, 4–8 ГБ оперативки, ~2 ГБ на диске, любой микрофон. Видеокарта не нужна.

## Чем отличается от полного Джарвиса

| | Полный Джарвис | Джарвис Лайт |
|---|---|---|
| Разговор | нейросеть (Ollama, ~5 ГБ) | заготовленные шутки, факты, ответы без повторов |
| Непонятная фраза | ответит ИИ | «Не понял команду… Или загуглить «…»?» |
| Видеокарта | желательна | не используется |
| Установка | 6–7 ГБ | ~1 ГБ |
| Лицо | 3D-голограмма | простое 2D-лицо (без камеры и фото) |
| Папки | `%LOCALAPPDATA%\Jarvis`, `Документы\Jarvis` | `%LOCALAPPDATA%\Programs\JarvisLite`, `%LOCALAPPDATA%\JarvisLite` |

Программы не мешают друг другу: разные установщики, папки, автозапуск, значки и пункты «Пуска». Только не
запускай обе одновременно: обе отзываются на «Джарвис».

## Нагрузка (замер)

Джарвис Лайт ждёт имени. Замер шёл 60 секунд после прогрева, со всеми частями программы и Whisper small в
памяти, на 8-ядерном ПК (`tests/smoke/measure_idle.py`):

| Режим | Процессор (сам Джарвис) | Память |
|---|---|---|
| Свёрнут в трей | ~2 % одного ядра (≈0,2 % всего ПК) | ~0,84 ГБ |
| Окно с лицом открыто | ~12 % одного ядра (≈1,5 % всего ПК) | ~0,85 ГБ |
| Без окна (`--no-gui`) | ~1,5 % одного ядра | ~0,8 ГБ |

Сверх этого ничего не работает в фоне: распознавание включается только на речь (VAD), процесс идёт с пониженным
приоритетом (BELOW_NORMAL), а потоки ограничены (4 по умолчанию, «Минимальная» нагрузка — 2). Большая часть
памяти — модель распознавания Whisper small (~0,55 ГБ). Модель `base` или `tiny` (Настройки → Микрофон) занимает
меньше памяти, но распознаёт хуже.

## Приватность

* Микрофон слушается только локально. Пока на значке пауза (`Ctrl+Alt+M`), звук не записывается совсем.
* Никаких облачных ИИ и отправки речи. В интернет уходят только поиск, погода, тревоги и проверка обновлений.
* Пароли и токены (Telegram, alerts.in.ua) хранятся в «Диспетчере учётных данных» Windows.
* Архив диагностики собирается без паролей и никуда не отправляется сам.

## Для разработчиков

```
python -m jarvis               # GUI
python -m jarvis --text        # текстовый режим
python -m jarvis --no-gui      # голос без окна
python -m jarvis --check       # проверка компонентов
python -m jarvis.watchdog      # запуск под сторожем (так стартуют ярлыки)
python -m jarvis.manual --write                 # обновить таблицы команд в docs/ИНСТРУКЦИЯ.md
pytest -q; ruff check .                         # тесты и линтер (requirements-dev.txt)
python tests/smoke/measure_idle.py --gui --tray # замер нагрузки в простое
scripts/build_installer.sh                      # сборка JarvisLiteSetup.exe (Inno Setup 6, Windows или Wine)
```

Внутренний пакет называется `jarvis`. Тест `tests/test_lite.py` проверяет, что в коде нет модулей ИИ и
обращений к Ollama: ни импортов, ни адресов `11434` / `/api/chat`, ни сетевых вызовов на обычных фразах. Ещё он
следит, чтобы распознавание всегда шло на CPU int8, а в репозитории не было фото лица.

## Лицензии сторонних ресурсов

Распознавание — [faster-whisper](https://github.com/SYSTRAN/faster-whisper) (MIT), модель Whisper (OpenAI, MIT).
Голос — [Piper](https://github.com/rhasspy/piper) (MIT); голос `ru_RU-denis-medium` скачивается при установке. Значок и 2D-лицо нарисованы
в коде этого проекта. Сторонних картинок в программе нет.
